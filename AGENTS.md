# Project Guidelines & Routing Rules

## URL Conventions

Always strictly follow the flat URL naming convention for all service and location pages.

### Correct URL Patterns
- **Service Pages:** `/<service-slug>`
  - Example: `/electrical-repairs-troubleshooting`
  - Example: `/plumbing-repair-portland-me`
  - Example: `/electrical-repairs`
- **Location / Service Area Pages:** `/<service-slug>-<location-slug>`
  - Example: `/electrical-repairs-zachary-la`
  - Example: `/electrical-installation-baton-rouge-la`

### Prohibited / Incorrect URL Patterns (Never create these)
- ❌ Do **not** nest service pages under `/services/` (e.g. `never create /services/electrical-repairs-troubleshooting`).
- ❌ Do **not** nest service area pages under `/service-areas/` (e.g. `never create /service-areas/portland-me`).
